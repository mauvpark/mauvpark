## 공개 프로젝트

### typetojson

**typetojson** 은 타입 혹은 인터페이스에서 default value 값을 쉽게 만들기 위해 만든 vscode 라이브러리입니다.

레포지토리: https://github.com/mauvpark/vscode-type-to-json

### random-serial-value-generator

**random-serial-value-generator** 는 주어진 배열 값들 중 하나를 랜덤하게 추출할 수 있는 javascript 라이브러리입니다.

레포지토리: https://github.com/mauvpark/random-value-generator

## 기타 프로젝트

### react-no-framework-sample

**react-no-framework-sample** 은 프레임워크 없이 리액트 프로젝트를 구성한 것으로 프론트 프로젝트의 기초 구조 설정 방법에 대해 참고할 수 있습니다.

레포지토리: https://github.com/mauvpark/react-no-framework-sample

### socketIO-client-example

**socketIO-client-example** 은 소켓 통신의 클라이언트 파트를 참고할 수 있도록 만든 레포지토리입니다.

레포지토리: https://github.com/mauvpark/socketIO-client-example

### socketIO-server-example

**socketIO-server-example** 은 소켓 통신의 서버 파트를 참고할 수 있도록 만든 레포지토리입니다.

레포지토리: https://github.com/mauvpark/socketIO-server-example
